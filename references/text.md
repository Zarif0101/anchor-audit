# Text module

- Match the length to the platform, then cut 15%.
- Paragraphs: 1-3 sentences, with uneven lengths on purpose.
- Captions and DMs: no markdown, no bullets, no headers.
- Long-form: headers only if a reader would scan for them. Never put a header over a single paragraph.
- One idea per piece. If there are two, make two pieces.
- Use contractions. Write the way he'd say it out loud.
- Never invent a number or quote. If a fact is missing, leave it out, or ask in Anchor intake.
- End on the last useful sentence. No call-to-action unless he asked for one.
