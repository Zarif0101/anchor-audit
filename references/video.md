# Video module (draft, untested)

Slot = the first line he would actually say on camera, typed or spoken.

## Script tells (audit only, plus everything in tells.md)
- Hooks like "Did you know...?", "Here's the thing", "Let's break it down", "You won't believe".
- Countdown lists by reflex ("3 tips to...").
- Every line the same length, ready to read off a teleprompter.
- A closing line that asks viewers to comment or like with no reason given.
- B-roll notes that could fit any video ("person typing on laptop").

## Moves
- Start mid-action, or on the most surprising true fact, inside 2 seconds.
- One claim per shot.
- Each script gets one shot only he could film (his desk, his street, his screen).
- Write for the ear: short words, repeat the key noun instead of swapping in a pronoun.
- For HeyGen or avatar videos, add one human-recorded element (his voice line, a real photo, a real screen).
