# Step 0: 30-minute self-test

Run on install and after a Claude model update (20 min the second time).

## Briefs (replace with your own if you have them)
1. A caption announcing something you made this week.
2. A 45-second Short script about one thing you learned the hard way.
3. A 150-word post with an opinion people in your field would argue with.

## Procedure
For each brief, in fresh chats:
- A: plain request, no skill.
- B: the same request with the skill (Lite).
Note the usage meter or message size before and after each run.

## Record
| Brief | Usage A | Usage B | Ratio B/A | Tells in A (count by tells.md category) | Tells in B | Which would you post? |
|---|---|---|---|---|---|---|

## Decide
- K0: if A already has almost no tells on your briefs, stop. You don't need this skill.
- K1: if the average ratio is over 2.2x, change Lite so the audit runs inside the draft turn with no separate pass, then retest once. Still over → drop the skill and use tells.md as a manual checklist.
- K2 (after 2 weeks): if you typed your own line in fewer than half of 5 Anchor tries, use Lite only. That's fine.
- K3 (after 5 paired pieces, advisory): if 2 readers prefer the skill version in none of 5, stop or redesign. 3 pieces can't tell you anything, so don't decide on fewer.

## Paired check (week 3)
Show 2 people who use ChatGPT/Claude a lot the A and B versions of 5 pieces, unlabeled and in random order. Ask which one a real person wrote, and which one they'd rather read.
